# 権限

Pateat は、機能に必要な範囲の権限を Chrome に求めます。
マニフェストにある各権限と、その用途を説明します。

| 権限 | 用途 |
| --- | --- |
| すべての HTTPS サイトへのアクセス（`https://*/*`） | ログインページの検出と操作、パスキー要求への応答、Bitwarden サーバーと Pateat サービスへの接続 |
| `storage` | 設定、レシピのコピー、保管庫への接続情報、サービスとのペアリングを Chrome に保存 |
| `offscreen` | 非表示の拡張機能ページで Bitwarden SDK を動かし、保管庫の復号とパスキー署名を実行 |
| `alarms` | サービスワーカーが休止中でも 5 分ごとに起動し、保管庫の次の同期時刻が来たかを確認 |

`tabs`、`scripting`、`activeTab`、`cookies`、`webRequest`、`history`、 `nativeMessaging`
など、それ以外の権限は要求しません。通常の HTTP ページでは動作しません。

## すべての HTTPS サイトへのアクセス

サイトごとに後から権限を求める方式ではなく、インストール時にすべての HTTPS サイトへの
アクセスを宣言します
（[ADR 0009・英語](https://github.com/risu729/pateat/blob/main/docs/adr/0009-install-time-https-site-access.md)）。
そのため、サイトを追加しても Chrome の確認は再表示されません。その代わり、Chrome は
すべてのウェブサイト上のデータの読み取りと変更が可能だと警告します。
Pateat のスクリプトは、すべての HTTPS ページに読み込まれます。

- ログイン用スクリプトは、各 HTTPS ページとフレーム内で動きます。
  ログインが許可されるまでは、ページの存在を Pateat
  のサービスワーカーに通知するだけです。
- パスキー用の 2 つのスクリプトは、HTTPS の最上位ページの読み込み開始時に動きます。
  1 つがページのパスキー要求（`navigator.credentials.get` と `create`）をラップし、
  もう 1 つが要求を Pateat のサービスワーカーへ中継します。
  Pateat が応答しない要求は、そのまま Chrome に渡され、Chrome、スマートフォン、
  他のパスキープロバイダーが応答できます。ただし、次の 3 つは例外です。
  アカウントを選ばないまま Pateat の選択画面がタイムアウトした要求は、Chrome 自身の
  タイムアウトした確認画面と同様に失敗します。Pateat がログインを完了した後の
  パスキー候補の要求は、ページがキャンセルするまで待機します。また、Pateat がそのタブを
  ログインさせた直後、保管庫内のパスキーを列挙して新しいパスキーを作成しようとする要求は
  拒否します。

読み込まれたすべてのページで操作するわけではありません。ログインするのは、除外されておらず、
保管庫のアイテムに一致するか、ユーザーがそのサイト用にアイテムを選んでいて、ページ用のレシピが
あり、Chrome のサイトアクセスも許可されている場合だけです。
入力するのは、そのオリジン、タブ、フレーム、ページについて、レシピで指定されたフィールドだけです。
レシピがないページは、作成のために Pateat サービスへ説明を送る場合があります。
含まれる情報は[プライバシーポリシー](./privacy.md)をご覧ください。

同じアクセス権で Bitwarden サーバーと Pateat サービスにも接続します。 Bitwarden
には、選んだサーバー上の、機能に必要な決まったエンドポイントだけを呼び出します。

## サイトアクセスを制限する

Chrome では、拡張機能のサイトアクセスを制限できます。 `chrome://extensions` の Pateat
のカードから **詳細** → **サイトへのアクセス** を開きます。 Pateat
はサイトごとの設定に従い、アクセスのないサイトではログインもパスキーへの応答も行いません。
Bitwarden サーバーや Pateat サービスに接続できない場合は、必要になった時に設定ページで
アクセス許可を求めます。

他のサイトでのアクセスを保ったまま 1
つのサイトだけ停止するには、ツールバーのポップアップで **Pateat on this site**
を無効にします。その除外設定は、同じサービスとペアリングした
すべての端末に反映されます。

## ストレージ

データは、Chrome の拡張機能専用ストレージ（`chrome.storage` と IndexedDB）に保存します。
ウェブサイトからは読み取れません。Chrome
から拡張機能を削除すると、そのデータもすべて削除されます。
