# プライバシーポリシー

::: warning 草案
このポリシーは、Pateat の最初の公開リリースと Chrome ウェブストアの掲載のために書いた草案です。現在の拡張機能の作りを説明したもので、弁護士の確認は受けておらず、まだ効力はありません。この日本語版は[英語版](../privacy.md)の翻訳で、内容が異なる場合は英語版が優先します。
:::

Pateat は、自分の Bitwarden 保管庫にあるアカウントでウェブサイトにログインする Chrome 拡張機能です。[risu729](https://github.com/risu729) がオープンソースソフトウェアとして開発しており、ソースコードは [GitHub](https://github.com/risu729/pateat) にあります。このポリシーについての質問は [pateat@takuk.me](mailto:pateat@takuk.me) に送ってください。

Pateat には分析、広告、トラッキングの仕組みはなく、開発者が拡張機能からデータを受け取ることもありません。データが端末から出るのは、次のサービスに届けるときだけです。Bitwarden サーバー、ペアリングした Pateat サービス（Cloudflare で動き、Anthropic または OpenAI を使います）、AI キーを保存した場合は選んだプロバイダーへ直接、ログインするウェブサイトです。

## 端末上 {#on-your-device}

Pateat は、次のものを Chrome 内の拡張機能自身のストレージに保存します。ウェブサイトからは読めず、拡張機能を削除すると消えます。

- **暗号化された保管庫。** 接続した各 Bitwarden 保管庫の写しで、Bitwarden が暗号化したままです。
- **ロック解除の鍵。** 保管庫のロックを解除している間、その写しを復号する鍵です。保管庫のタイムアウトが **なし** のときは、Chrome を再起動しても保管庫が自動でロック解除されるよう拡張機能のストレージに保存し、OS のキーストアでは保護されません。ほかのタイムアウトではメモリーにだけ置きます。**ロック** と **ログアウト** で消えます。
- **Bitwarden の同期用のログイン情報。** マスターパスワードなしで保管庫を同期し直すために使います。マスターパスワードと確認コードは保存しません。保管庫のロックを解除するときや、再要求が設定されたアイテムのためにマスターパスワードを入力したときは、Pateat が端末上で確かめ、どこにも送りません。
- **AI プロバイダーの API キー。** 保存した場合だけで、今日と今月に使った金額も保存します。暗号化せずに保存し、選んだプロバイダー（Anthropic または OpenAI）にだけ送ります。
- **接続ごとの情報。** 接続の名前、Bitwarden サーバー、メールアドレス、Pateat が Bitwarden で使うデバイス識別子です。
- **設定とレシピ。** Pateat サービスと同期したもの（保管庫ごとに設定したアイテムとフィールドの制限、サイトが求めた個人情報をどの保管庫のアイテムが持つか、保管庫のタイムアウト、言語とテーマ、AI キーの上限額を含みます）と、サービスとのペアリングの認証情報です。
- **ログインの進み具合。** タブとサイトごとに、ログインがどこまで進んだか、どのアカウントを選んだか、ログアウトしたかパスキーでサインインしたかを、ログインを誤って繰り返したり再開したりしないために保存します。
- **エクスポートファイル。** エクスポートしたときだけ、Chrome のダウンロード先に保存します。Pateat サービスが保存する設定（保管庫のアカウントとアイテムの名前を含みます）とレシピが入り、保管庫の鍵や値、サービスのサインイン情報、AI キーは入りません。Pateat はこのファイルをどこにも送りません。インポートしたファイルは、インポートした端末の上で読みます。
- **診断ログ。** 不具合の報告のために、Pateat がしたことを記録します。サイト、ページのアドレス（パラメーター名は残し、値は残しません）、タブ ID を記録し、保管庫の値は記録しません。最長 14 日間保存します。警告、エラー、Pateat が何もしなかった理由は、後で説明するとおり Pateat サービスにも送ります。それ以外は、自分でダウンロードして共有しない限り端末に残ります。ログを保存またはコピーする前に、直近の期間や、そうした警告、エラー、理由だけに絞り込めます。プレビューには保存されているログのうち何件を含むかが表示されます。絞り込んでもログは削除されません。

保管庫の値は、拡張機能の中で動く公式の Bitwarden SDK が端末上でだけ復号します。以下で説明する SSO のプロバイダーラベルを除き、値が拡張機能から出るのは、そのアイテムを使えるサイトのログインページに入力するときだけです。保管庫のアイテムのウェブサイトに一致するサイトか、そのアイテムを選んだサイトです。カード番号のように、ウェブサイトを持たないカードや ID のアイテムの値は、ポップアップでリンクを確定したログインアイテムのサイトにだけ入力します。

## SSO の方法 {#sso-methods}

保存した SSO の対応付けは、この端末に残ります。選んだサイトとプロバイダーのアイテムへの参照、プロバイダーのログイン先、アイテムの変更を確かめるための情報を保存します。復号した SSO フィールド、ラベル、ユーザー名、ユーザー名を比較するための証明は保存しません。中断した操作については、アカウントとページへの参照や操作の識別子をセッション内に残しますが、それを使って操作の許可を復元することはありません。

SSO の入口のレシピを作成・修復するとき、Pateat は選んだ方法の括弧内のプロバイダーラベルを、伏せ字処理済みのサイトのページの記述と一緒に、ペアリングしたサービスと選んだ AI プロバイダーへ送ります。ペアリングせず自分のキーを使う場合は、プロバイダーへ直接送ります。URL 形式の方法では、選んだページ上のボタンなどのラベルに、ページの記述と同じユーザー名の伏せ字処理を端末上で適用して使います。サービスは以下の依頼ログの規則に従って保存します。SSO フィールドの残り、プロバイダーのユーザー名、比較用の証明、保存した対応付けは送りません。プロバイダーアカウントの認証情報は、許可されたログイン先でだけ使います。

元のサイトに戻った後、端末上の情報だけでログインを確認できない場合は、そのページの伏せ字処理済みの記述も同じ経路で選んだ AI プロバイダーに送ることがあります。学習したログイン完了の目印はレシピに保存します。次回以降も、その時点のページで成功の根拠を確認します。

## Bitwarden サーバー {#your-bitwarden-server}

Pateat は、選んだ Bitwarden サーバー（Bitwarden クラウド（米国）、Bitwarden クラウド（EU）、自分の Bitwarden サーバー、Vaultwarden）と、Bitwarden 自身のアプリと同じようにブラウザーから直接通信します。目的は、アカウントの鍵の設定を調べる、メールアドレス、マスターパスワードから作ったハッシュ、入力した確認コード、デバイス識別子と名前（Bitwarden のデバイス一覧に Pateat が出るように）でログインする、その方式を選んだときに確認コードをメールで送るようサーバーに依頼する、暗号化された保管庫を同期する、診断ページのためにサーバーのバージョンを読む、です。サーバーが何を保存するかは Bitwarden の[プライバシーポリシー](https://bitwarden.com/privacy/)に従います。

## Pateat サービス {#your-pateat-service}

Pateat は、ペアリングした Pateat サービスと設定とレシピを同期します。サービスはそれぞれ持ち主が運用し、持ち主は保存された内容を読めます。今のところ、どのサービスも運用者本人だけが使っています。拡張機能がサービスに送るのは次のものです。

- **デバイス名。** ペアリングのときに入力したもので、選んだ設定プロファイルか新しいプロファイルの名前も送ります。サービスは、デバイスをペアリングした日時と最後に使われた日時も記録し、サービスにログインしたアカウントで利用者を識別します。
- **設定。** 設定プロファイルごとに、除外したサイト、許可したサイトと許可サイトだけで動かすかどうか、マスターパスワードを求めるサイト、パスキー要求をブラウザーに任せるサイト、サイトごとの既定のアカウント、Pateat が使える保管庫のアカウント・グループ・アイテム・フィールド、最後に確認したときの各アイテムの暗号化されたカスタムフィールドの指紋（ハッシュ）、ポップアップに **このページ** を表示するかどうかを送ります。すべてのプロファイルに共通で、どの保管庫のフィールドがサイトのログインのどこに入るかと、サイトが求める個人情報をどの保管庫のアイテムのどのフィールドから入力するかも送ります。既定のアカウント、アイテムとフィールドの制限、フィールドの割り当ては、保管庫のアイテムとアカウントの ID、アイテムと接続と選んだグループの名前、カスタムフィールドの名前で表します。個人情報のリンクは、アイテムとアカウントの ID とフィールド（カスタムフィールドはその名前）だけで表し、アイテムの名前は含めません。秘密の質問を確定したときは、サイトの質問を正規化した形でも送ります。保管庫の値は送りません。
- **ページの記述。** サイトにまだレシピがないとき、レシピがページに合わなくなったとき、ログインで次のページの記述が必要なときに送ります。記述するのは、ログインページ、選ぶアカウントが並ぶページ、個人情報を求めるページ、サイトのトップページの **Sign in** ボタンのようにログインページへの入口だけがあるページです。記述に含まれるのは、クエリ文字列とフラグメントを除いたサイトのアドレス（パスのうち ID、トークン、メールアドレスのように見える部分は `[id]` に置き換えます）、ページのタイトル、言語、見出し、フォームのフィールド・チェックボックス・ボタン・リンクについてはそのラベル、名前、プレースホルダー、説明、入力のヒント（必要な長さや `autocomplete` の値など）、`id`・`name`・`data-testid`・`data-test` の属性、テキスト、ページに並ぶ最大 8 件のアカウントのテキスト（`Taro [email] Last used` など）です。ページの画面上のキーボードは、それを囲む要素の `id`、`data-testid`、クラスで表し、キーは記述しません。選択肢のリストはラベルで表し、選択肢は記述しません。フィールドの値、非表示のフィールド、ページの HTML、スクリーンショットは送りません。
- **送る前に伏せるもの。** ページのテキストにあるメールアドレス、伏せ字、長い数字はプレースホルダーに置き換え、そのサイトのユーザー名もテキストのどこに出ても置き換えます。アドレスや名前にそうしたユーザー名を含むリンクとボタンは除き、パスにユーザー名を含むページは送りません。ユーザー名が 3 文字より短いとき、メールアドレスの `@` より前だけが表示されているとき、サイトのホスト名の一部のとき（`taro.example.com` など）、Pateat から除外したとき、保管庫を読めなかったときは、ユーザー名は伏せられません。ログインページの要素の `id`、`name`、`data-test` の属性値は、ページにあるとおりに送ります。表示名のように、ページに出るほかの名前は見分けられないので、そのまま送ります。
- **ログインに保管庫から必要なもの。** ログインページ、個人情報を求めるページ、ログイン後のページの記述と一緒に送ります。ページに入力できそうなカスタムフィールドの名前と、ユーザー名の形とテキストのカスタムフィールドの形（長さ、数字や文字などどの種類の文字があるか、メールアドレスかどうか）です。値そのものと、非表示のフィールドの形は送りません。アカウントが並ぶページと、ログインページへの入口だけのページには付けません。
- **ログイン後のページ。** ログインのあとに表示されたページを同じように記述し、ヘッダーのテキスト、リンクのアドレス、開いているダイアログ、コードの入力欄やボタンの近くのテキストを加え、数字はすべて置き換えて送ります。サービスがログインに成功したかを判断するためです。サイトのレシピが動くようになってからも、レシピがログインできているかをあとで確かめるため、各デバイスは 30 日に 1 回まで、ログイン後のページを送ります。
- **レシピの使用。** レシピでのログインが始まったとき（入力だけのログインも含みます）、レシピ、その版、使ったレイアウトを送り、レシピがまだ使われていることをサービスに知らせます。
- **ログインの記録**（[ADR 0055](https://github.com/risu729/pateat/blob/main/docs/adr/0055-login-records-sent-to-the-service.md)、英語）。レシピに従ったログインが終わったとき、どう終わったか（ログインできた、止められたなどの決まったコードと、その理由）、拡張機能のバージョン、かかった時間を送ります。時間は、サービス、ネットワーク、サイト、あなた（確認コードを入力していた間など）を待った時間に分けます。記録にはアドレス、ページのテキスト、ユーザー名、値は含みませんが、サービスはレシピからサイトがわかるので、いつどのサイトにログインしたかがわかります。
- **問題の報告**（[ADR 0066](https://github.com/risu729/pateat/blob/main/docs/adr/0066-problem-lines-sent-to-the-service.md)、英語）。診断ログの警告とエラーの行、ページで Pateat が何もしなかった理由の行を自動で送ります。時刻、拡張機能のビルド、ログのランダムな ID も付けます。行に含まれるのは、決まったコード、エラー名と Pateat 自身のコード内の位置、数、フラグ、レシピの ID、タブ ID、パスキーを求められたサイト、サイトだけです。設定していないサイトは、サービスが元のサイトに戻せないコードとして送ります。ログインがまだ何も送信していないときの一部の行には、ページのパスを含めます。ID、トークン、メールアドレスはページの記述と同じように置き換えますが、そのパスの中のユーザー名は伏せません。値、ページのテキスト、クエリ文字列は送りません。

ログインの記録と問題の報告は、既定で送ります。設定ページの **サービスへの報告** で、すべてのデバイスについてどちらも止められます。止めている間に記録したものは、後から送りません。

サービスは、書いたレシピを、各部分をどのモデルがいつ、どのデバイスの依頼で書いたかと一緒に、その部分が消されるまで保存します。90 日使われなかったレシピや、レシピの別のレイアウト（代替レイアウト）は消し、消したレシピがあったという記録は残します。受け取ったページの記述（モデルに尋ねたときはその回答も）、ログインの記録、問題の報告を、ダッシュボードに表示する、レシピの書き方を評価して改善する、Pateat の不具合を見つけて直すために保存します。保存期間は 1 年です。決まった時刻の削除はなく、古いものは、あとでページの記述、ログインの記録、問題の報告、レシピの同期がサービスに届いたときに消えます。さらに、モデルが判断した各ページについて、サイト、ページのパス、日時、結果を、サイトのレシピが変わるまで保存します。書くよう依頼されたレシピのサイトとパスも、同じレシピを二度書かないよう 10 分間保存します。

開発者は、開発者自身のログインだけがある自分のサービスから、確認したページの記述を、保管庫に由来する名前と形を作りものに置き換えて評価用データとして公開することがあります。ほかの人のサービスのものは公開しません。

サービスが拡張機能に発行するデバイスの認証情報は、90 日使われないと期限が切れます。

## Cloudflare {#cloudflare}

Pateat サービスは Cloudflare で動きます。コードは Cloudflare Workers、データは Cloudflare D1、ペアリングと管理のページへのログインは Cloudflare Access です。拡張機能がサービスに送るものはすべて、サービスの持ち主の Cloudflare アカウントの条件の下で Cloudflare を通り、そこに保存されます。Cloudflare はサービスのリクエストログを、アドレスのクエリ部分を除いて保存します。

## Anthropic {#anthropic}

Anthropic が選ばれている場合、レシピを書くときやログインを判断するとき、Pateat サービスは、上のページの記述とログインに保管庫から必要なものを、持ち主が設定した Claude の認証情報を使い、持ち主の Anthropic アカウントの条件の下で、Anthropic の AI モデルである Claude に送ります。モデルは持ち主がサービスの **Claude** または **OpenAI** ページで選びます。選んでいなければ Claude Opus 5.5 を使い、Opus 5.5 が依頼を断ったときは Claude Sonnet 5.5 に 1 度だけ尋ねます。

端末に Anthropic API キーを保存した場合は、サービスが作った依頼を拡張機能に返し、拡張機能があなたのキーで Anthropic に送り、Anthropic の回答をサービスに返します。サービスはそれを上と同じように保存します。このとき Anthropic は、キーの持ち主のアカウントの条件の下で依頼を扱います。キーはサービスに送りません。

SSO のプロバイダーラベルを除き、Pateat は、保管庫の値、ログインの記録、問題の報告、30 日に 1 回送るログイン後のページを Anthropic に送りません。

## OpenAI {#openai}

OpenAI を選んだ場合、サービスは、同じ伏せ字処理済みのページの記述と、ログインに必要な保管庫のフィールドの情報を、サービス上のあなたのアカウントに保存したキーで OpenAI に送ります。キーはサービスのデータベースに暗号化して保存されます。管理ページには設定済みかだけを表示し、キーの値は表示しません。**OpenAI** ページの **Remove saved key** で削除できます。サービスの運営者は暗号化用の鍵を管理し、キーにアクセスできます。

端末に OpenAI キーを保存した場合、ペアリングしたサービスは送る依頼を拡張機能に渡し、拡張機能が OpenAI に直接送ります。回答だけがサービスに戻り、キーは戻りません。ペアリングしていない場合、拡張機能が依頼を作り、レシピを端末に保存します。端末の既定モデルは GPT-6.1 Sol、依頼を断った場合の代替は GPT-6.1 Terra で、推論量は low、速度は standard です。

SSO のプロバイダーラベルを除き、保管庫の値、ログインの記録、問題の報告、30 日に 1 回送るログイン後のページは OpenAI に送りません。Pateat は回答の保存を無効にしますが、OpenAI がデータを一切保持しないという意味ではありません。通常最長 30 日間の不正利用監視用の保持、例外、アカウントの制御、プロンプトキャッシュの保持については OpenAI の[データ制御](https://developers.openai.com/api/docs/guides/your-data)を参照してください。API データは、利用者が同意しない限り学習に使われません。キーの持ち主のアカウントの条件に従います。

## ログインするウェブサイト {#the-websites-you-log-in-to}

ログインのため、Pateat はユーザー名、パスワード、ワンタイムコード、その他の保管庫のフィールドをサイトのログインフォームに入力し、サイトのパスキー要求にパスキーの署名で応答します。サイトはそれを、あなたが入力したときと同じように、サイト自身のプライバシーポリシーの下で受け取ります。`http://` のアドレスで保存したアイテムにだけ使う HTTP のページでは、入力したものは暗号化されずに送られます（[権限](./permissions.md#plain-http-pages)）。

## 接続の情報 {#connection-information}

上のサービスとログインするウェブサイトは、Pateat が接続するたびに、ふつうのウェブのリクエストと同じように IP アドレスなどの接続の情報を受け取ります。それぞれのポリシーの下で運用のログに保存することがあり、Pateat はそこから消せません。

## データを消す {#deleting-your-data}

- **端末上**：設定ページで保管庫の接続を削除するか、Chrome から拡張機能を削除します。拡張機能を削除しても、サービス側のデバイスは取り消されません。先に設定ページで接続を解除するか、サービスの **Devices** ページで取り消してください。
- **サービス上**：サービスのページで、除外したサイト、許可したサイト、既定のアカウント、フィールドの割り当てを外し、レシピとそのレイアウトを取り消せます。取り消したレシピは、取り消したという記録が残ります。マスターパスワードを求めるサイトは拡張機能で外します。**Request log** ページの **Delete all** で、保存されたページの記述、ログインの記録、問題の報告をすべて消し、レシピの各部分をどのモデルが書いたかの記録から、デバイスと依頼を外します。どのデバイスも使っていない設定プロファイルは、最後の 1 つを除いて **Profiles** ページで削除でき、そのサイトの設定、既定のアカウント、アイテムとフィールドの制限が消えます。プロファイルの名前は、それを使っていたデバイスのために残ります。デバイスの接続を解除するか取り消すと同期は止まりますが、デバイスの記録は残ります。次のものには削除の操作がありません。個人情報のリンク、デバイスの記録、削除したプロファイルの名前、判断したページとレシピの修復の記録、レシピの各部分をどのモデルが書いたかの記録、推論に使った金額の記録です。サービスの持ち主はデータベースから消せます。
- **AI キー**：設定ページの **キーを削除** で端末からキーを消せます。使った金額は、拡張機能を削除するまで残ります。
- **なくした端末**：サービスで取り消すとサービスに接続できなくなりますが、端末にすでにある保管庫の写し、ロック解除の鍵、レシピは消せません。
- **Bitwarden、Cloudflare、Anthropic、OpenAI**：それぞれのポリシーに従います。

## Chrome ウェブストアの Limited Use {#chrome-web-store-limited-use}

Pateat が受け取る情報の使用と移転は、[Chrome ウェブストアのユーザーデータに関するポリシー](https://developer.chrome.com/docs/webstore/program-policies/policies)（[Limited Use](https://developer.chrome.com/docs/webstore/program-policies/limited-use) の要件を含みます）に従います。特に次のとおりです。

- Pateat は、扱う認証情報とウェブサイトの内容を、単一の目的（選んだサイトにログインし、何をしたかを表示すること）を提供し改善するためにだけ使います。
- その情報は、このポリシーに書いたとおり、その目的のためにだけ移転します。保管庫のログインと同期のために Bitwarden サーバーへ、ユーザー名、パスワード、ワンタイムコード、個人情報、その他の保管庫のフィールド、パスキーの署名をログインするサイトへ、設定、ページの記述、ログインの記録、問題の報告を Cloudflare で動くペアリングした Pateat サービスへ、ページの記述を、カスタムフィールドの名前、ユーザー名とテキストのフィールドの形（値は含みません）、選んだ SSO のプロバイダーラベルと一緒に、そのサービス経由で、または自分の API キーで端末から直接、選んだプロバイダー（Anthropic または OpenAI）へ移転します。
- ユーザーデータを販売せず、広告のために使ったり移転したりせず、信用力の判断や貸付のために使ったり移転したりしません。
- 開発者は、ほかの人が Pateat を使って生じたデータを受け取らず、読みません。Pateat サービスの持ち主は自分のサービスに保存された内容を読めますが、今のところどのサービスも運用者本人だけが使っているので、それは本人のデータです。
