# プライバシーポリシー {#privacy-policy}

::: warning 草案
初回の一般公開と Chrome ウェブストアへの掲載に向けた草案です。
現在の実装を説明していますが、弁護士による確認は受けておらず、まだ発効していません。
:::

Pateat は、自分の Bitwarden の保管庫にあるアカウントでウェブサイトにログインする Chrome
拡張機能です。[risu729](https://github.com/risu729) がオープンソースとして開発し、
ソースコードを [GitHub](https://github.com/risu729/pateat) で公開しています。

アクセス解析、広告、トラッキングの機能はなく、開発者へ利用データを自動送信する機能もありません。
端末からデータを送る相手は、以下で説明する Bitwarden サーバー、ペアリングした Pateat
サービス （Cloudflare 上で動き、Anthropic の Claude
を利用）、ログイン先のウェブサイトだけです。

## 端末に保存するもの {#on-your-device}

以下のデータを、Chrome の拡張機能専用ストレージに保存します。
ウェブサイトからは読み取れず、拡張機能を削除すると消去されます。

- **暗号化された保管庫。** 接続した Bitwarden の各保管庫の、Bitwarden が暗号化したままの
  コピーです。
- **ロック解除キー。** Chrome の再起動後もそのコピーをロック解除するためのキーです。 OS
  のキーストアでは保護されません。自動ロック解除を無効にすると削除され、自動ロック解除を
  有効にしてサインインし直すまで、その保管庫は使えなくなります。
- **Bitwarden の同期用サインイン情報。** マスターパスワードを再入力せずに同期するための
  情報です。マスターパスワードや確認コードは保存しません。
- **設定とレシピ。** Pateat サービスから同期した設定とレシピ、保管庫ごとのアイテムや
  フィールドの利用制限、サービスのペアリング用認証情報です。
- **ログインの実行状態。**
  誤って操作を繰り返したり再開したりしないように、タブとサイトごとに
  どこまで進んだかを保存します。
- **診断ログ。** 不具合の報告に使う操作記録です。サイトやページのアドレスを記録し、
  パラメーターは名前だけで値は記録しません。保管庫の値も記録しません。
  自分でダウンロードして共有しない限り、端末にとどまります。

保管庫の値は、拡張機能内の公式 Bitwarden SDK で、端末内でのみ復号します。
値を拡張機能の外に出すのは、そのアイテムを使ってよいサイトのログインページに入力するときだけです。
対象は、保管庫に登録したウェブサイトと一致するサイト、またはユーザーがそのアイテムを選んだ
サイトです。

## Bitwarden サーバー {#your-bitwarden-server}

選んだ Bitwarden サーバー（Bitwarden Cloud US、Bitwarden Cloud
EU、または自分のサーバー）に、ブラウザーから直接接続します。Bitwarden
公式アプリと同様に、アカウントのキー設定を取得し、
メールアドレス、マスターパスワードから導いたハッシュ、入力した確認コード、端末 ID
と端末名でサインインして、暗号化された保管庫を同期します。端末 ID
と名前によって、Bitwarden の端末一覧に Pateat が表示されます。
サーバー側の保存情報には、[Bitwarden のプライバシーポリシー](https://bitwarden.com/privacy/)が
適用されます。

## Pateat サービス {#your-pateat-service}

ペアリングした Pateat サービスと設定やレシピを同期します。
サービスの運用者は、保存されるデータを読むことができます。
現在は各運用者が自分用のサービスを運用しています。拡張機能が送る情報は次のとおりです。

- **端末名。**
  ペアリング時に入力した名前です。サービスはペアリング時刻と最終使用時刻も記録し、
  サービスへのサインインに使ったアカウントで利用者を識別します。
- **設定。**
  除外したサイト、サイトごとの既定のアカウント、ログインの各部分にどの保管庫の
  フィールドを使うか、という設定です。保管庫のアイテム ID とアカウント ID に加え、
  アイテム名、接続名、カスタムフィールド名を含みます。
- **ログインページの説明。**
  レシピがまだないサイトや、ログインの次のページを説明する必要が
  ある場合に送ります。クエリ文字列を除いたサイトのアドレス、ページのタイトル、見出し、
  フォームのラベル・名前・プレースホルダー、ボタンやリンク、アカウント一覧のテキストを含みます。
  フィールドの値、非表示フィールド、HTML、スクリーンショットは送りません。
  メールアドレス、伏せ字、長い数字は送信前に置換し、そのサイト用のユーザー名もページ内の
  テキストに現れた場所で置換します。ただし、3 文字未満のユーザー名、メールアドレスの `@`
  より
  前だけを表示したもの、サイトのアドレスに含まれるもの、保管庫を読み取れなかったもの、
  ログインページへのリンクだけを提供するページでは、ユーザー名が残ります。
  表示名など、その他の名前は判別できず、そのまま送信します。
  ログイン後のページも同様に説明し、ヘッダーのテキスト、開いているダイアログ、コード入力欄や
  ボタンの近くのテキストを含めます。その場合は桁数によらず数字を置換し、ログインが成功したかを
  サービスが判断します。
- **ログインに必要な保管庫の情報の種類。**
  ページに入力できるカスタムフィールドの名前と、
  ユーザー名やテキスト型カスタムフィールドの値の形を、ページの説明と一緒に送ります。
  形とは、長さ、数字や文字などの文字種、メールアドレスかどうかです。値そのものは送りません。

サービスは作成したレシピを保存し、Claude
に送ったリクエストとその回答を、レシピ作成の評価と
改善のために保持します。リクエストの保持期間は 90
日で、その後の同期がサービスに届いた時に
削除します。この記録から、どのサイトにログインするかが分かります。
運用者が自分のサービスのログからページの説明を公開する場合は、内容を確認し、保管庫由来の
名前や値の形を架空のものに置き換えた評価データにします。
開発者が行うのは、開発者自身のサービスにあるデータについてだけです。

## Cloudflare {#cloudflare}

Pateat サービスのコードは Cloudflare Workers、データは Cloudflare D1、サインインは
Cloudflare Access を使います。拡張機能からサービスに送る情報は Cloudflare を通過し、
同社上に保存されます。サービス運用者の Cloudflare アカウントの規約が適用され、
Cloudflare はサービスへのリクエストログも保持します。

## Anthropic {#anthropic}

レシピを作成したりログインの成否を判断したりする際、Pateat
サービスは、上記のページの説明と必要な保管庫情報の種類を、Anthropic の AI モデル Claude
に送ります。サービスの運用者が設定した Claude の認証情報を使います。保管庫の値は
Anthropic に送りません。受け取った情報の扱いには、その運用者の Anthropic
アカウントの規約が適用されます。

## ログイン先のウェブサイト {#the-websites-you-log-in-to}

ユーザー名、パスワード、ワンタイムコードなどの保管庫のフィールドをログインフォームに入力し、
パスキー要求には署名で応答します。サイトは、ユーザーが操作した場合と同様にこれらを受け取り、
そのサイト自身のプライバシーポリシーに従って扱います。

## データの削除 {#deleting-your-data}

- **端末上。** 設定ページで保管庫への接続を削除するか、Chrome から拡張機能を削除します。
- **サービス上。** 管理画面で、除外サイト、既定のアカウント、フィールドの選択を削除し、
  レシピを取り消せます。ただしレシピを取り消した記録は残ります。
  端末の切断や認証の取り消しでは、同期は止まりますが端末の記録は残ります。
  Claude に送ったリクエストは、90 日の保持期間が過ぎるまで残ります。
  端末の記録やリクエストログを削除する画面はまだありません。運用者がデータベースから
  削除することはできます。
- **Bitwarden と Anthropic。** それぞれのポリシーに従います。

## Chrome ウェブストアの Limited Use {#chrome-web-store-limited-use}

Pateat
が受け取る情報の利用は、[Chrome ウェブストアのユーザーデータに関するポリシー](https://developer.chrome.com/docs/webstore/program-policies/policies)
と、その
[Limited Use（使用制限）](https://developer.chrome.com/docs/webstore/program-policies/limited-use)
の要件に従う方針です。具体的には次のとおりです。

- 扱う認証情報やウェブサイトのコンテンツは、選んだサイトへのログインとその結果の表示という
  単一の目的の提供と改善にだけ使います。
- 情報を送るのは、このポリシーに記載した範囲で、その目的のためだけです。
  保管庫のサインインと同期は Bitwarden サーバーに、設定とログインページの説明は
  ペアリングした Pateat サービスに送ります。サービスは Cloudflare 上で動き、
  そのサービスから Anthropic に情報を送ります。
- ユーザーデータを販売せず、広告のために利用・転送せず、信用力の判定や融資のためにも
  利用・転送しません。
- 開発者は利用者のデータを読みません。Pateat
  サービスの運用者は、自分のサービスに保存された情報を読むことができます。
