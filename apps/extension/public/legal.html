Bitwarden OSS SDK

The local cryptographic host and synthetic probe use the unmodified GPL edition of @bitwarden/sdk-internal 0.2.0-main.1034, with source revision 7de8f13a14b56068167160f88d55231f916cf16a. Pateat's integration was added on 2026-10-10. Bitwarden does not support this third-party integration.

Matching SDK source archive · Upstream build instructions

A distributed extension binary must be accompanied by its matching Pateat and dependency source with build/install instructions. The download location must identify that exact revision; the repository homepage alone is not that source offer. A local development build uses the accompanying working source tree.
